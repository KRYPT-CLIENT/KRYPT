A clean interface

Settings should be easy to navigate and the visual design should stay out of the way while you play.

Personal customization

A foundation for player preferences, visual options, and a setup that feels personal.

Responsiveness is a design goal. Performance claims will be based on testing, not promises.

02 / About KRYPT

A client project, built in public.

KRYPT is an independent project for Minecraft players. This site is the home for project information, development notes, and future releases.

The project is still being developed, so the feature list may change. When builds are available, this page should point to the actual downloads and explain which Minecraft versions they support.

Want to follow along or contribute? The repository is the best place to find the source, report problems, and suggest improvements.
